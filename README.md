# 다운로드 정리

파일을 다운로드하면 "어디에 둘까요?" 창이 떠요. 폴더 이름을 입력하면 비슷한 폴더를 찾아 주고,
누르면 파일을 그 폴더로 옮겨요. 한 번 고른 폴더는 기억해서 다음부터 맨 위에 보여줘요.

- "공학수학2"로 `공수2` 폴더처럼 줄임말도 찾아요.
- 추천에 없으면 "다른 폴더 고르기"(Ctrl+O)로 직접 고를 수 있어요.
- 작업 표시줄 오른쪽 아래(시계 옆) 아이콘으로 켜져 있는지 확인할 수 있어요.

Windows 10/11(64비트)에서 동작해요.

## 설치

1. [최신 배포 페이지](https://github.com/ahhopglza9/download-organizer/releases/latest)에서
   **DownloadOrganizer-Setup.cmd**를 받아요.
2. 브라우저가 "흔히 다운로드되지 않는 파일"이라고 하면 **유지**를 눌러요.
   <!-- 화면 캡처 자리 -->
3. 받은 파일을 더블클릭해요. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 눌러요.
   서명 인증서가 없는 프로그램이라 뜨는 경고예요. 설치 파일은 메모장으로 열어 내용을 볼 수 있어요.
   <!-- 화면 캡처 자리 -->
4. 1분 정도 기다리면 "어느 폴더에서 찾을까요?" 화면이 떠요. 확인하고 **시작하기**를 눌러요.

업데이트는 자동이에요. 새 버전이 나오면 다음에 켤 때(켜 둔 채라면 하루 안에) 알아서 받아요.

## 쓰는 법

- 파일을 다운로드하면 창이 떠요. 어디에 둘지 입력하고 Enter.
- ↑↓로 고르기, Esc는 다운로드 폴더에 그냥 두기.
- 시계 옆 아이콘 우클릭: **설정**(찾아볼 폴더, 자동 실행, 기억 지우기), **끄기**.

## 제거

**설정 → 앱 → 설치된 앱**에서 "다운로드 정리"를 찾아 제거해요.
설정과 고른 폴더 기억도 함께 지워져요.

## 문제가 생기면

`%LOCALAPPDATA%\DownloadOrganizer\data` 폴더의 `app.log`(실행 기록)와
`설치기록.txt`(설치 기록)를 [이슈](https://github.com/ahhopglza9/download-organizer/issues)에 첨부해 주세요.

## 개발

```bash
python -m pip install uv
python -m uv sync
python -m uv run pytest -q
python -m uv run python main.py
```

새 버전 배포: `python release.py 1.2.3` (GitHub CLI `gh` 로그인 필요)
